# Contributing

Corrections to these pages are welcome: a wrong number, a claim that does not match the code, a broken link, a status
that is out of date, or an unclear explanation. Open an issue with the "Report correction" template and point to the
file and line, or send a small pull request. Changes to findings must keep `python3 tools/check_consistency.py`
passing.

The code lives in the Hoosat repositories, and that is where code, bug reports and design discussion belong:

| You want to… | Go to |
|---|---|
| Report a bug in the node, propose or review a code change | [HoosatNetwork/HTND](https://github.com/HoosatNetwork/HTND) (issues and pull requests, see its CONTRIBUTING.md) |
| Report a bug in the stratum bridge or propose a change | [HoosatNetwork/htn-stratum-bridge](https://github.com/HoosatNetwork/htn-stratum-bridge) |
| Discuss development | The [Hoosat Discord](https://discord.gg/EE5ZcTeuj), Development category: `#node` (HTND), `#miners` (bridge and mining), `#research` (this tracker), `#testnet` |
| Report a security vulnerability | See [SECURITY.md](SECURITY.md); never in a public issue |

Pull requests that change HTND or bridge behaviour will be closed with a pointer to the right repository.
