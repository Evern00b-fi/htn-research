# Security

**Do not report vulnerabilities in a public issue, here or in the Hoosat repositories.**

This repository contains no software that runs on a node. If you find a vulnerability in HTND, report it
privately through GitHub's private vulnerability reporting on the HTND repository:
<https://github.com/HoosatNetwork/HTND/security/advisories/new> (the "Report a vulnerability" button on its
Security tab). The stratum bridge repository has no such channel; use the HTND form for bridge issues as well,
or contact the Hoosat developers privately on the [Hoosat Discord](https://discord.gg/EE5ZcTeuj).

Security-sensitive findings from this work are reported privately to the Hoosat developers and are not described in
this repository. Each is published after a fix is released and a disclosure date is agreed with them.

If something on these pages exposes information that should not be public, open an issue titled
"Please contact me" without details, and the author will get in touch privately.
