# Figures

All figures are standalone SVG files generated by `tools/make_figures.py`. The first four use the Python 3 standard
library only; the two added later (`pp-move-cascade.svg`, `gbt-cache-before-after.svg`) use matplotlib, keep text as
SVG text, and also get a PNG preview at twice the width. Each SVG carries `<title>` and `<desc>` elements with the full
data for screen readers, uses a white background, Helvetica/Arial and the Okabe-Ito colour-blind-safe palette, and is
laid out for 700 px width. The matplotlib figures assert that every plotted number appears in its source text and
recompute the Wilson intervals from the published counts.

Regenerate all figures from the repository root:

```sh
python3 tools/make_figures.py        # needs matplotlib for the last two figures; skips them with a note otherwise
python3 tools/check_consistency.py   # verifies that the numbers embedded in the SVG text match the reports
```
